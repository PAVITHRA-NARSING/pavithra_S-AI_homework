Question Title: Data Breach Response

Question Link: https://my.newtonschool.co/playground/code/orlr84xpc3oo?lecture_hash=vifkrugjcwth

Solution:
#!/bin/bash
cd breach_response || exit 1
cp evidence/log_dump.txt log_dump.txt
chmod u+w evidence
mv evidence secure/
chmod 555 secure/evidence
chmod u+w reports/incident_summary.txt
echo "Breach confirmed" >> reports/incident_summary.txt
chmod 444 reports/incident_summary.txt
echo "Forensics Complete" > secure/forensics_report.txt
chmod 600 secure/forensics_report.txt
chmod u+w reports/incident_summary.txt
echo "Escalated to security team" >> reports/incident_summary.txt
chmod 444 reports/incident_summary.txt

Approach:
Copy the log file to the main directory. Temporarily grant write permission to the evidence directory so it can be moved into secure, then restore its required permissions. Temporarily allow changes to the incident summary, append both required messages, and restore read-only permissions each time. Finally, create the forensics report and set its permissions to 600.
